🎬方法A：ブラウザソースに直接（おすすめ）

OBS 28 以降に内蔵の WebSocket で字幕を送ります．背景は透過，クロマキー不要，見た目はこの画面と同じです．

  1. OBS の「ツール」→「WebSocket サーバー設定」で「WebSocket サーバーを有効にする」にチェック
    「パスワードを表示」でパスワードを確認（認証なしでも可）
  2. 下にパスワードを入れて「OBSに接続」
  3. 「現在のシーンに字幕を追加」を押す
    ブラウザソース「jimakuChan 字幕」が自動で追加されます．手動で追加したい場合は下の URL をブラウザソースに貼ってください
オーバーレイURL
テキストソースに文字だけ送る（上級）

OBS の「テキスト」ソース名を入れると，そのソースの文字列を直接書き換えます（見た目は OBS 側で設定）．

🟩方法B：ウィンドウキャプチャ＋クロマキー（従来）

OBS が古い／WebSocket を使いたくない場合．「表示モード」で設定を隠して字幕だけにし（v1 と同じ），この Chrome ウィンドウを OBS でウィンドウキャプチャして，フィルタ「クロマキー」で緑を抜きます．次回からは同じ URL を開くだけで表示モードで始まります．

  1. 「表示モード」ボタンで設定を隠す（クリック／Esc で戻る）
  2. OBS で「ウィンドウキャプチャ」→ そのウィンドウを選択
  3. ソースを右クリック →「フィルタ」→「クロマキー」（緑）
※ 認識はこのタブで動きます．タブは閉じないでください

💡ヒント

  • 全画面ゲーム中に認識が止まる場合は「保存・起動」タブの起動ファイル（.bat / .command）を使ってください
  • マイクは Chrome の既定デバイスが使われます．変えたい場合は OS の入力デバイスを切り替えてください
  • OBS のブラウザソースは「表示されていないときにソースをシャットダウン」を OFF にしてください

🙈センシティブワードの伏字

単語リストは goodBadWordlist（皆で育てるリスト）を認識言語・翻訳言語ごとに自動で読み込みます．英語などは単語単位で判定するので "class" の "ass" のような誤伏字は起きません．

追加で伏せる語（1行1語）
伏せない語（誤検出の回避，1行1語）

📝語句置換

認識結果の文字列を置き換えます（表示・翻訳・OBS すべてに反映）．1 行に 1 つ「置換前→置換後」．

💾設定ファイル

全プリセット（GAS キー・OBS 設定を含む）を 1 つの JSON ファイルに保存／読込します．別 PC や起動ファイル用プロファイルへの引っ越しに．

🚀起動ファイル（全画面ゲーム中も止まらない）

Chrome の省電力で認識が止まるのを防ぐ起動ファイルを作ります．専用プロファイルで開くので，初回はそちらで「ファイルから読込」してください．
